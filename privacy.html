Privacy Policy

Last updated: October 15, 2026

Anmatos is a personal assistant used by a single person, its owner, on his own computer. This policy explains how it handles data, including data from Google APIs.

What data it accesses

With the owner's explicit consent, Anmatos reads the owner's own Gmail messages using the read-only Gmail scope (gmail.readonly). It cannot send, delete or modify e-mail. It does not access anyone else's account.

How the data is used

  • To keep the owner's personal memory and reminders up to date and to answer the owner's own questions.
  • Security-related e-mail (login codes, password resets, security alerts) is filtered out automatically before processing.
  • Text needed to answer the owner's request may be processed by a language model provider (OpenAI) on the owner's behalf, under the owner's own account.

Storage and sharing

Data is stored locally on the owner's computer. It is not sold, not shared with third parties for advertising, and not used to train models. Access tokens are stored in the macOS Keychain.

Google API Services User Data Policy

Anmatos's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The owner can delete locally stored data at any time.
